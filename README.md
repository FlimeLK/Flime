# 🌻 Мафія: Хутір

Telegram-бот для гри в «мафію» в українському сільському антуражі: 🏠 **Мирні** проти 🌑 **Мафії**, плюс одинаки.

## Запуск

Потрібні Python 3.11+ і PostgreSQL.

```bash
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env              # впиши BOT_TOKEN, дані PostgreSQL і свій OWNER_IDS
python -m bot
```

Таблиці створюються автоматично в окремій схемі `hutir`, тому стара база бота в тій самій БД залишається недоторканою.

На сервері: `deploy/systemd/mafia-bot.service` (запускає `python -m bot`), резервні копії: `deploy/backup_db.sh`.

## Як грати

1. Додай бота в групу.
2. `/game`: починається реєстрація. Гравці тиснуть «Долучитися» (бот відкриється в особистих).
3. Роль приходить в особисті. Вночі кнопки дій теж приходять в особисті.
4. Вдень обговорення, потім голосування в особистих і підтвердження страти 👍/👎 у групі.

### Предмети

Купуються за 🪙 шаги в `/shop`. На старті гри до 3 різних предметів (VIP — 4) беруться в кишеню. Невикористані предмети повертаються після гри.

🧿 Оберіг · 🧄 Часник · 🐴 Підкова · 🕯 Свічка · 🎭 Маска колядника · 🔱 Вила · 🍯 Мед

### Валюти і VIP

- 🪙 **Шаги**: заробляються в грі (10 за участь, +40 за перемогу) і щоденним `/daily`.
- 💎 **Червінці**: купуються за ⭐ Telegram Stars і обмінюються на шаги або VIP.
- 👑 **VIP**: ×1.5 шагів за гру, більший щоденний бонус, +1 предмет у кишеню.

Усі числа економіки зібрано в `bot/economy.py`.

## Оформлення: персонаж і меню

Бот говорить від імені персонажа **Кум Опанас** («Отакої!»). Змінити персонажа, ім'я й описи бота можна в константах `PERSONA`, `CATCHPHRASE`, `BOT_NAME`, `BOT_ABOUT`, `BOT_DESCRIPTION` у `bot/texts.py`. Ім'я, About і Description бот сам оновлює в Telegram при запуску, аватарку ставлять у @BotFather (`/setuserpic`).

- `/start` показує привітання й меню: зверху «💬Кумова порада», під ним сітка розділів по 2 кнопки, знизу «Покликати на вечорниці». Розділи відкриваються в тому самому повідомленні, кнопка «⬅️На поріг» повертає в меню.
- `/settings` у групі (для адмінів) відкриває «⚙️Налаштування хутора:» з модулями Годинник, Хто є хто, Віче, Комора і кнопкою «🔄Освіжити».
- Клавіатури меню лежать у `bot/keyboards.py`, callback_data з префіксами `menu:`, `sec:`, `set:`.

## Анімовані емодзі та медіа

Бот показує **анімовані (Premium) емодзі** в текстах і на кнопках, а кнопки мають кольори (зелені, червоні, сині). Для анімації потрібен **Telegram Premium у власника бота** (правило Telegram). Якщо Telegram відхилить якийсь емодзі, бот сам надішле те саме повідомлення зі звичайними емодзі. Вимкнути анімацію: `PREMIUM_EMOJI=0` у `.env`.

Емодзі за замовчуванням узято з офіційного пака анімованих емодзі Telegram і відкритого каталогу [telegram-premium-emojis](https://github.com/abbosahmad/telegram-premium-emojis). Замінити будь-який можна командами власника в особистих з ботом (`/design` покаже довідку):

- `/emoji`: усі ключі та поточні емодзі.
- `/emoji_set КЛЮЧ 🔥`: надішли premium-емодзі одразу після ключа (або відповідай на повідомлення з ним).
- `/emoji_id`: відповіддю на повідомлення з premium-емодзі покаже їхні ID.
- `/emoji_pack НАЗВА`: підбере збіги з пака `t.me/addemoji/НАЗВА`; `/emoji_pack НАЗВА apply` застосує їх.
- `/emoji_reset КЛЮЧ`: повернути емодзі за замовчуванням.

**Медіа для сцен:** відповідай на фото / GIF / відео командою `/media СЦЕНА` (список сцен: `/media`). Сцени: привітання, збір гравців, початок гри, ніч, ранок, голосування, страта, перемога кожної сторони, картка кожної ролі. Без медіа бот надсилає оформлений текст.

## Команди

**Група:** `/game`, `/start_now`, `/leave`, `/stop` (адмін), `/settings` (адмін), `/top`, `/rules`

**Особисті:** `/start`, `/profile`, `/shop`, `/daily`, `/vip`, `/promo КОД`, `/rules`

**Власник** (`OWNER_IDS`): `/owner`, `/design`, `/emoji…`, `/media…`, `/give`, `/vip_give`, `/block`, `/unblock`, `/broadcast`, `/promo_new`, `/promo_list`, `/promo_del`, `/purchases`, `/refund`, `/games`

## Структура

```
bot/
  engine/    чиста логіка гри без Telegram (ролі, предмети, ніч, голосування, перемога)
  game/      ведучий гри: фази, таймери, клавіатури
  handlers/  обробники команд і кнопок
  db/        PostgreSQL (asyncpg) і міграції
  texts.py   усі тексти
  economy.py ціни й нагороди
tests/       pytest
```
